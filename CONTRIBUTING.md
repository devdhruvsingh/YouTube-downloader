# Contributing to MediaMorph

Thank you for your interest in contributing to MediaMorph! Whether it's bug reports, feature requests, or code contributions, all help is greatly appreciated.

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug, please create an issue on GitHub and include:
* A clear description of the problem.
* Steps to reproduce the issue.
* Your environment details (OS, browser, python version, etc.).

### 2. Suggesting Enhancements
If you have a feature idea or improvement, open an issue to discuss it before starting work.

### 3. Pull Requests (PRs)
1. Fork the repository and clone it locally.
2. Create a new branch for your feature or bugfix (`git checkout -b feature/amazing-feature`).
3. Make your changes and ensure everything runs smoothly.
4. Commit your changes (`git commit -m "feat: add amazing feature"`).
5. Push to the branch (`git push origin feature/amazing-feature`).
6. Open a Pull Request on GitHub.

## Development Guidelines
* Follow clean code principles and maintain consistency with the existing codebase.
* Test your code locally (both backend FastAPI and frontend React) before submitting a PR.
* Keep commit messages descriptive and clear.

Thank you for helping make MediaMorph better!
